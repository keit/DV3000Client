## Install

Built for **x86_64**, Ubuntu 24.04 or newer (and other distributions of a similar age for the AppImage).

**.deb** (Ubuntu / Debian-based):

```sh
sudo apt install ./dv3kclient_*_amd64.deb
```

**AppImage** (any distribution):

```sh
chmod +x DV3KClient-x86_64.AppImage
./DV3KClient-x86_64.AppImage
```

Before the first connect, follow [Getting Started](https://keit.github.io/DV3000Client/getting-started.html): serial port access for a ThumbDV plugged into the PC, or the AMBEServer setup if it's on another machine.

`SHA256SUMS` lists the checksums of every file below; `dv3kclient-*.tar.gz` is the complete source, submodules included.
